# Use the within transformation from the plm package

Use the within transformation from the plm package

## Usage

``` r
Within_plm(df, effect = "twoways")
```

## Arguments

- df:

  A data.frame object

- effect:

  The fixed effect specification. Values possible: "twoways" (default),
  "individual", "time", "nested"

## Value

A data.frame object with the transformation complete
